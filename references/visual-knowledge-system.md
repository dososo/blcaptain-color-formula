# BLCaptain 摄影视觉、调色与审美知识系统 v3

本文件是执行设计基线，不是风格词典或万能参数表。目标是把色彩科学、摄影视觉语言、电影调色、获奖作品判断和计算摄影转译成可以检查、执行、失败和回退的规则。

## 一、总原则：技术正确是地基，视觉表达才是结果

一张作品至少同时存在七个层面：

1. **事实层**：主体、环境、事件与真实颜色是否仍可信。
2. **观看层**：第一眼、第二眼和最后停留在哪里。
3. **空间层**：前中后景、尺度、遮挡、负空间与深度是否成立。
4. **光影层**：明暗面积、光线方向、软硬、轮廓和反射是否共同讲述情绪。
5. **色彩层**：主色、辅色、强调色、冷暖、综合色彩重量和记忆色是否有秩序。
6. **材质层**：细节、微对比、颗粒、光晕、黑位密度和高光质地是否统一。
7. **意义层**：画面为何值得看、保留了什么、隐藏了什么、离开后记住什么。

World Press Photo把视觉质量、故事和表达责任并列；Hasselblad Masters把概念强度、原创性、创造力和技术完成度并列。故“更锐、更亮、更饱和”只能描述操作，不能证明作品更好。

## 二、场景参照与显示参照

### 2.1 两种信号不能混为一谈

- **场景参照**：RAW、Log、线性光或明确相机输入变换，描述拍摄场景的相对光能。
- **显示参照**：JPEG、社交平台图片、Rec.709成片，已经包含相机或软件的渲染选择。

显示参照素材不能通过曲线“恢复”已经剪切或被相机降噪抹掉的信息。后期可以重新组织现有信号，但不能凭空制造真实布光、景深或细节。

### 2.2 完整链路

```text
输入解释
→ 工作空间
→ 一级校正
→ 局部塑形
→ 创意渲染
→ 色域压缩
→ 显示编码
→ 观看条件复核
```

ACES 2.0将Rendering Transform和Display Encoding分开；渲染部分又区分明度J、综合色彩M和色相h。这说明创意影调、综合色彩和设备编码不应由一条RGB曲线同时承担。

### 2.3 色域和观看条件

- 色域标签、白点、传递函数、矩阵、范围和位深必须进入方案指纹。
- sRGB、Display P3、Rec.709、P3影院、PQ和HLG不是“颜色更多或更高级”的同义词。
- 同一像素值在不同色域和传递函数中不是同一颜色或亮度。
- CIECAM16说明颜色外观与采用白点、环境亮度、背景和适应状态相关；色差不等于观看感受。

## 三、曝光、影调与曲线

### 3.1 曝光意图

线性光中，中间调目标用相对EV描述：

```text
Y_target = clamp(Y_source × 2^ΔEV, Y_floor, Y_ceiling)
ΔEV = log2(Y_target / max(Y_source, ε))
```

v3禁止把所有素材硬拉向固定中位亮度。清透、低调、夜景和高调人像可以有不同的相对EV与上下限，但必须先尊重源素材的光线结构。

### 3.2 五段影调

1. **黑位**：是否存在真正的视觉锚点，而非通道死黑。
2. **趾部**：暗部如何进入黑位；抬趾产生雾化和胶片底色，压趾产生密度与重量。
3. **中间调**：主体可读性、肤色和大部分材质所在区域。
4. **肩部与高光滚降**：亮部进入高光的方式；决定柔和、通透、金属或数字感。
5. **白位**：最高亮强调及显示余量，不等同于所有高光都推到白。

### 3.3 曲线不是五个图标

- 上拉／下压只说明局部导数方向，不说明作品目标。
- S曲线增加某一枢轴附近的对比，但可能同时堵暗部、剪高光、增加肤色饱和。
- 反S降低全局反差，但若没有局部对比和综合色彩分离，会变成灰片。
- 胶片感不是简单抬黑压白；它还需要肩趾形状、密度依赖色彩、颗粒与高光质地。
- RGB通道曲线改变色彩平衡；在显示编码空间直接强拉会同时改变明度与色相。

曲线应保持单调，推荐用分段单调插值。设控制点 `(x_i, y_i)`，要求：

```text
0 = x_0 < ... < x_n = 1
0 ≤ y_0 ≤ ... ≤ y_n ≤ 1
```

但“单调、安全”仍不代表方向正确。

### 3.4 局部对比

全局影调跨度和局部对比必须分开。局部对比可用多尺度亮度差描述：

```text
LC_s = mean(|Y - G_s(Y)|)
```

其中 `G_s` 为尺度`s`的平滑。小尺度控制纹理，中尺度控制立体感，大尺度控制区域塑光。单纯锐化不能替代区域光影。

## 四、白平衡、色适应与混合光

白平衡不是“让所有中性物变灰”，而是决定观众将哪个光源视为环境白。

基本流程：

```text
RGB → XYZ → LMS
LMS_adapted = D × LMS
XYZ_adapted = M^-1 × LMS_adapted
```

`M`可以来自Bradford或CAT16，`D`由源白点、目标白点与适应程度决定。混合光下全局白平衡无法同时中和所有区域；必须选择叙事主光，或使用局部选区。故暖室内保留窗外冷色并非白平衡失败，可能是空间层次。

## 五、综合色彩、HSL与感知空间

### 5.1 三个不同概念

- **Chroma／彩度**：相对于同亮度中性轴的距离。
- **Colorfulness／综合色彩**：在具体观看条件下感到颜色有多强。
- **Saturation／饱和感**：综合色彩相对于亮度的比例感。

全局Saturation滑杆同时推所有颜色，容易产生红脸、荧光绿、塑料蓝和高光染色。自然饱和类操作应优先增加低彩区域，保护已饱和区域。

### 5.2 明度依赖饱和

建议使用钟形权重保护极暗与极亮：

```text
w(L) = smoothstep(L_a, L_b, L) × (1 - smoothstep(L_c, L_d, L))
C_out = C_in × (1 + k × w(L))
```

这样可以增强中间调颜色，同时避免黑位和彩色高光爆裂。

### 5.3 HSL的能力与边界

HSL适合人工理解的宽色带微调，但其色相区间、亮度定义和插值随软件不同；橙色色带不等于肤色语义蒙版，蓝色色带不等于天空。HSL必须与主体检查、边界羽化和邻近色影响同时验收。

### 5.4 OKLab／OKLCH与CAM16／JMh

- OKLab／OKLCH适合做近似感知均匀的差异、调色盘和综合色彩限制。
- CAM16考虑观看条件；ACES 2.0的JMh渲染思路将明度J、综合色彩M、色相h分开。
- 这些空间不是自动审美模型；它们只让控制更接近人的感觉。

### 5.5 记忆色

肤色、天空、植被、食物、木材等具有强记忆预期。允许创意偏移，但必须回答：

- 偏移是叙事需要还是技术污染？
- 主体与环境是否都向同一颜色坍缩？
- 是否保留了能让观众相信材质的综合色彩差异？

## 六、构图、形状、线条与观看路径

构图不是三分法模板，而是视觉重量的组织。

### 6.1 观看路径

```text
第一眼锚点 → 第二层关系 → 环境信息 → 余韵区域
```

明度、综合色彩、清晰度、尺度、面孔、文字、消失点和孤立元素都会争夺注意。调色应强化既有观看路径，而不是让背景比主体更亮、更彩、更锐。

### 6.2 视觉对立

- **明／暗**：可读与隐藏、开放与压迫。
- **冷／暖**：空间、时间、亲疏与光源关系。
- **大／小**：力量、尺度、脆弱与环境压力。
- **动／静**：方向线、模糊、瞬间与稳定结构。
- **虚／实**：注意、记忆、距离与心理状态。
- **疏／密**：呼吸、孤独、信息密度与紧张。
- **正／负空间**：主体存在和沉默区域。

这些关系没有固定好坏，关键是是否服务命题。

### 6.3 构图改变必须独立确认

裁切、旋转、透视、电影画幅和内容移除都会改变作品语义。系统可以建议，但必须单独展示收益和代价；默认只调色。

## 七、光线与局部塑形

光线判断至少包括：方向、面积、软硬、色温、主辅比、轮廓、反射、遮挡和高光形状。

### 7.1 后期可做

- 重排已有亮度关系；
- 用几何渐变或区域蒙版强化已有方向；
- 控制主体／背景综合色彩和局部对比；
- 柔化或收紧高光；
- 控制环境色污染。

### 7.2 后期不能诚实宣称

- 生成拍摄时不存在的真实光源与阴影几何；
- 从纯白剪切恢复纹理；
- 在没有语义蒙版时自动保护肤色、天空或商品；
- 用暗角冒充主体塑光。

局部能力分四级：

```text
L0 全局调整
L1 几何局部：渐变、椭圆、固定区域
L2 语义局部：人物、皮肤、天空、植被、建筑
L3 时序语义局部：视频跟踪、遮挡与镜头切换
```

能力声明必须显示实际等级。

## 八、材质、锐度、颗粒与光学感

- **锐度**关注边缘；**清晰度／微对比**关注中尺度结构；**纹理**关注细节频段。
- 过度锐化会产生白边、黑边、皮肤干裂和视频振铃。
- 降噪应先于锐化；色噪、亮度噪声和压缩块需要不同处理。
- 胶片颗粒不是均匀数字噪点；它与亮度、综合色彩、画幅和扫描有关。
- 辉光／Bloom来自亮区扩散；Halation更偏向高亮边缘的乳剂／片基回散特征。两者不能用全画面模糊代替。
- 高级质感通常来自材质间差异仍然存在：皮肤、石材、金属、织物、雾和天空不能被同一锐化与同一综合色彩压成一种表面。

## 九、常用审美词的可执行拆解

### 9.1 清透干净

- 中间调可读、白点干净但不漂白；
- 暗部有空气而非抬成灰；
- 综合色彩有分离，低彩区域不脏；
- 局部对比集中于主体；
- 禁忌：全局加曝、青白肤色、塑料天空、去雾过度。

### 9.2 治愈感

- 低冲突的观看路径、较大呼吸空间；
- 暖或中性中间调、柔和肩部、克制暗部；
- 少量柔化和自然材质；
- 禁忌：满屏橙黄、黑位消失、主体无锚点。

### 9.3 高级感

- 不是低饱和的同义词；
- 清楚的层级、有限调色盘、稳定材质、克制强调色；
- 黑白端有控制，综合色彩不互相污染；
- 每个夸张都有理由，并知道哪里不动；
- 禁忌：所有参数平均用力、廉价青橙、肤色和背景同色。

### 9.4 电影感

- 来自画面设计、镜头、光线、美术、运动、剪辑、声音和调色的共同语言；
- 后期部分包括镜头匹配、肩趾、颜色世界、肤色与环境分离、材质和时序连续；
- 黑边、颗粒和青橙只能是可能手段，不是定义。

### 9.5 清冷感

- 冷环境不等于把所有通道变蓝；
- 通常保留中性或微暖生命色，使冷空间更可信；
- 高光、阴影和中间调可具有不同冷暖关系；
- 禁忌：尸白肤色、蓝灰污染、综合色彩全部消失。

### 9.6 Ins风

“Ins风”不是一个可验证的单一风格，应拆为：明亮生活方式、奶油柔光、低彩极简、复古闪光、旅行高彩、都市冷调等子家族。系统必须询问或根据参考选择子方向，不能输出一套万能参数。

### 9.7 氛围感

氛围是空间、光线、颜色、材质、天气、时间和叙事距离共同产生的感受。若主体与环境没有关系，仅加雾、暗角和偏色不会自动得到氛围。

## 十、大师与获奖作品的可转译方法

### 10.1 Ansel Adams：预视觉化与影调控制

Zone System的价值不是把数字区间机械套到所有照片，而是拍摄前先想象最终影调，再控制曝光、显影和打印使之实现。转译到Skill：先建立视觉命题和目标影调，再执行；不能从滑杆倒推故事。

### 10.2 William Eggleston：颜色是内容

MoMA对其作品的历史说明强调，颜色不是独立装饰，而是图片内容和经验的一部分。转译：不要把蓝天、红墙、黄灯视为可随意替换的色块；先判断颜色在故事中的作用。

### 10.3 Saul Leiter：遮挡、反射与留白

其彩色作品提示我们，虚、遮挡、玻璃、天气与负空间可以比直接展示更有情绪。转译：系统不能把所有低对比、雾和遮挡都诊断为需要去除的问题。

### 10.4 Alex Webb：复杂层次与综合色彩秩序

复杂、鲜艳不等于混乱。前中后景、光影边界、动作与颜色可同时构成多层观看路径。转译：高级感不应默认去饱和；综合色彩可以强，但必须有空间和叙事组织。

### 10.5 顶级评审共同点

综合World Press Photo、Hasselblad Masters和FilmLight Colour Awards：

- 技术完成只是门槛；
- 作品必须具有观点、故事或情绪；
- 原创性来自选择和限制；
- 强画面常常同时清楚又保留不可一次说尽的部分；
- 视频调色需从现场、样片、剪辑到最终交付保持共同语法。

## 十一、计算摄影SOTA的可用与不可用

### 11.1 可吸收

- MIT-Adobe FiveK：同一RAW存在五位专家的不同成立处理，适合训练与评估“多解”而非唯一答案。
- Deep Bilateral Learning：低分辨率预测、双边空间局部仿射、高分辨率边缘保持应用，证明局部、内容相关调整可高效实现。
- 3D LUT／条件LUT：适合确定性颜色映射和视频时序稳定，但不能自动处理所有局部光线或语义问题。
- 参考驱动视频调色：语义对应与确定性映射有助于镜头一致，但仍需处理错误对应、伪影和用户控制。

### 11.2 不可冒充

- NIMA等自动审美分数是群体数据的弱代理，可能偏向数据集流行风格；不能证明个人偏好、文化语境、故事真实性或获奖级作品。
- PSNR、SSIM、色差和直方图相似不能证明观看路径与情绪一致。
- 参考迁移不能只匹配全局均值；语义不对应会造成肤色、天空和物体错色。
- 视频逐帧模型即使单帧漂亮，也可能闪烁、漂移或在镜头切换时崩溃。

## 十二、视频调色专门原则

```text
输入变换
→ 镜头检测
→ 每镜头一级校正
→ 同场景镜头匹配
→ 场景／段落共享外观
→ 局部跟踪
→ 时序与压缩检查
→ 输出变换
```

必须分别检查：

- 短期闪烁：相邻帧亮度、综合色彩和局部区域突变；
- 长期漂移：同一人物／场景跨时间颜色渐变；
- 镜头匹配：切换前后主体、白点、对比与综合色彩连续；
- 动态局部：蒙版抖动、边缘穿帮、遮挡恢复；
- 编码：色带、暗部块、锐化振铃、颗粒压缩；
- 交付：色彩标签、范围、音频、帧率和时长。

## 十三、条件化视觉蓝图

正式配方不再只是参数表：

```text
配方 = 视觉命题
     + 适用条件与反例
     + 相对影调策略
     + 综合色彩与记忆色规则
     + 主体／环境层级目标
     + 材质策略
     + 媒体执行差异
     + 风险与回退
     + 晋级证据
```

每套配方至少声明：

- `tone_span`：increase／preserve／compress；
- `colorfulness`：increase／preserve／decrease；
- `subject_separation`：increase／preserve；
- `local_contrast`：increase／preserve／soften；
- `texture`：clean／soft／grain／crisp。

方向门只检查结果是否与声明相反，不声称自动判断艺术价值。

## 十四、七层评测

1. **合同安全**：确认、原件、输出、哈希、覆盖、失败原子性。
2. **色彩技术**：色域、白点、传递函数、范围、位深、剪切、色带。
3. **感知方向**：影调跨度、综合色彩、局部对比、主体分离是否符合蓝图。
4. **视觉层级**：第一眼、背景竞争、形状和空间是否更清楚。
5. **风格成立**：主手势、综合色彩语法、材质和禁止项是否同时成立。
6. **用户偏好**：盲测选择、情绪词、记忆点、拒绝原因与修改语言。
7. **视频时序**：镜头匹配、闪烁、漂移、局部跟踪、压缩和完整回放。

必须保留如下边界：

> 不能用自动分数冒充审美。自动指标负责发现退化和技术风险；作品是否动人、独特、真实、具有文化与个人意义，仍需人类判断。

## 十五、普通用户界面

内部知识可以复杂，用户流程保持：

```text
上传
→ 一句话视觉诊断
→ 3个方向／查看全部
→ 强度与可选构图
→ 简洁确认单
→ 生成原图／结果／A-B
→ 接受或自然语言修改
```
