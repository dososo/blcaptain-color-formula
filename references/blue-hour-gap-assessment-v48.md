# v4.8 蓝调家族空缺评估

## 结论

本轮**不新增**蓝调配方。现有 `blue-hour` 已覆盖黄昏民用暮光的低照度蓝底与残余暖光；`cool-gray-sea`、`captain-deep-sea`、`night-cool-neon`、`rainy-blue-green` 和 `rain-ink-neon` 分别覆盖冷灰水体、深蓝风光、城市霓虹与潮湿夜色。继续按名称扩充只会增加重叠，不能证明新的视觉问题被解决。

## 当前数值边界

- `blue-hour` 的适用核心是：暮光低照度、蓝底主导、仍存在少量暖色人造光或地平线余光。
- 白天冷灰风景优先走 `cool-gray-sea`，不得把“偏蓝”自动解释为蓝调时刻。
- 高彩霓虹夜景优先走 `night-cool-neon`／`rain-ink-neon`；它们的色彩锚点与蓝调时刻的低彩底不同。
- 纯深蓝自然风光可评估 `captain-deep-sea`，但其尺度感与蓝调时刻的城市／暮光叙事不同。

## 新配方晋级条件

只有出现至少一组许可真实素材，满足以下全部条件，才允许新增：

1. 现有蓝调相关配方均因**同一个可解释缺口**失败，而不是强度不合适；
2. 新方案在 55%／80%／100% 上变化单调且三档均无新增剪切；
3. 与 `blue-hour` 的影调、暖冷锚点和主辅色色相差至少有一个数值互斥边界；
4. 真实渲染、方向验证、独特性互斥与人工观看记录齐全；
5. 参数为项目原创，不引用商业 LUT、第三方预设或受限制参数包。

当前独立评审集尚未提供足够的民用暮光细分样本，因此“宁缺毋滥”优先于增加目录数量。
