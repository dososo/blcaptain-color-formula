# 工作流补充：指导模式

当用户选择“告诉我怎么调”时，进入指导模式。本模式只提供人工操作建议，不调用渲染，不生成新文件，也不展示伪造的前后对比。

## 1. 只补齐必要信息

优先使用用户已经提供的信息。进入本模式后最多再问三项，每次只给 2～3 个选项：

1. **使用什么软件**：例如 Lightroom、剪映、DaVinci；用户不确定时可提供“手机简单调”“电脑精细调”两个方向。
2. **想要什么感觉**：根据素材给出 2～3 个互斥选项，例如“清透自然”“温暖胶片”“冷调电影”。
3. **想调多明显**：“轻微”“适中”“明显”。如果用户已经说清强度，可把这一问换成“最在意什么”，例如“肤色自然”“天空层次”“整体氛围”。这只是人工验收重点，不代表自动局部处理。

不要询问已经能从素材或用户描述中确定的内容，也不要一次展示完整风格库。

## 2. 先给指导确认单

使用以下普通用户可读的格式：

> **调色指导确认**
>
> - 软件：剪映
> - 效果：清透自然
> - 强度：适中
> - 主要方向：压住过亮部分、提一点暗部、减轻偏黄
> - 人工留意：脸不要发灰，天空不要出现色块
> - 说明：这些数值是未标定的手动起点，会受原素材、软件和滤镜版本影响。本次不会处理或生成文件。
>
> 确认后，我再按这个方向给你具体步骤和参数。要继续吗？

用户只有在确认这份内容后，才进入参数输出。若软件、风格、强度或主要方向变化，重新展示确认单并再次确认。

## 3. 确认后的输出顺序

按用户在软件中实际操作的顺序输出，避免堆砌术语：

1. **先修明暗**：告诉用户先观察什么，再给参数范围。
2. **再校正冷暖和偏色**：解释画面目标，不承诺不同软件数值相等。
3. **再调整颜色浓淡**：优先给安全范围，提醒观察肤色和高饱和区域。
4. **最后加质感**：锐化、清晰、颗粒、暗角等放在最后，并给出减弱条件。
5. **如何检查**：建议在同一屏幕上反复开关效果，查看脸、天空渐变、黑位和亮部细节。

参数优先使用范围，例如“高光先试 -20～-35”，不要把启发式起点写成唯一正确值。每组参数后附一句可操作的回退方法，例如：“脸发灰时，把冷暖向暖色回 3～8 格，或把整体强度降低一级。”

## 4. 专业格式和能力边界

- Display P3 照片可走本地渲染模式并保持 P3。遇到 RAW、Log、HDR/PQ/HLG、Dolby Vision、Adobe RGB、ProPhoto RGB、DCI-P3、BT.2020、广色域视频或其他未知 ICC，停止给出一键套用参数；说明需要先在支持色彩管理的软件中正确解释素材，再提供保守操作顺序。
- 不把一个软件的滑杆数值直接换算成另一个软件的精确数值。跨软件参数只能标为未标定起点。
- 指导模式本身不运行语义蒙版，也不得声称已经替用户完成局部选区；可以建议用户在目标软件中手动建立选区。本地渲染模式另有可选 L2 路径：plan 显式加 `--detect-local`、对应后端与类别真实可用，并在 render 用 `--confirm-local` 单独确认后，才会执行人物／肤色／天空等已探测策略。多人肤色按人物实例一对一派生，匹配失败的实例会明确降级；这不等于任意类别或跨帧跟踪都可用。

## 5. 修改和收口

参数给出后，询问用户结果更接近哪一种：

- “偏冷／偏暖”
- “偏暗／偏亮”
- “太浓／太淡”

只根据用户选择修改相关参数。先提交新的指导确认单，用户确认后再输出新版参数，避免多轮参数互相叠加而失去基准。

最终明确说明：这是人工操作建议，没有调用 `render`，没有修改原文件，也没有生成结果文件。
