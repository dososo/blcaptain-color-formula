# 公开测试范围与已知限制

状态：v4.9.0 公开测试范围。GitHub、Release 与冷安装状态以对应标签和 Release 页面为准；本文不表示全部审美通过。

## 本次产品承诺

用户提供自己的JPEG／PNG照片或普通SDR视频，在本地完成诊断、方向选择、确认方案、生成新文件、查看前后对比及反馈。原文件不覆盖。视频成片与短对比预览分别标识；短预览不能当完整连续回放，必须打开成片核对声音和全程画面。

全局调色是核心；可选语义模型、视频语义跟踪、相机Log／HDR转换、跨App实机标定均不属于首发默认可用承诺。低对比画面不能仅凭外观认定为Log。

## 当前目录不是全部已完成风格

32条历史记录保留：3条自动推荐重做位、1条需明确点名的人工可执行位、28条研究候选。照片和视频的实际权限以 `list-styles` 及计划检查为准；目录准入不表示任意素材均成功或效果已经被接受。

| 方向 | 入口 | 当前需要知道的限制 |
|---|---|---|
| natural-clean | 自动推荐／明确选择 | 已有素材级人工接受；只做诊断需要的 Foundation 修复，健康素材可能明确返回无需修复 |
| celadon-forest | 自动推荐／明确选择 | 抬黑发灰问题已在照片覆盖中修复并有素材级人工接受；仍须逐素材预演，不外推为全素材通过 |
| silver-morning-mist | 自动推荐／明确选择 | 照片和视频均有素材级人工接受；肤色、黑位与综合色彩仍按每张素材独立检查 |

不得将以上已知效果缺陷隐藏为“模型没有安装”，也不得把它们全部归因于用户原片。未修好的素材／风格组合保留失败记录。

## 首发验收和长期目标分开

首发门：干净目录能启动核心入口；真实照片及有声视频完整链路；错误可解释且不留下半套结果；源文件哈希不变；包中没有用户媒体和秘密；发布文件与Git内容可追溯；公开展示素材有再分发依据。相关回归失败必须修复或明确证明不属于承诺范围，不能靠跳过或改变预期凑绿。

长期目标继续执行：全部31套照片优化、全部视频风格正式接入、局部和时序能力、跨App标定。每套形成“原片—基础校正—风格成片”对比，适合灰片则优先使用，保留强度、适用范围和失败原因。先做执行方自审，再交队长逐套判断可接受／需修改／不可接受；失败项不能从图谱消失。

## 安装与许可边界

候选包需Python及独立安装的FFmpeg／ffprobe，不捆绑这些程序或模型。Python 3.9+ 是无第三方包的核心运行合同；完整开发仓库的研究、数值与可选能力测试固定使用带开发依赖的 Python 3.10.18，二者不得混称“双解释器全量”。FFmpeg构建配置、编解码器及可选依赖各有自身许可，项目MIT不替它们重新授权。当前实际验证平台为macOS；其他平台尚未验证。

场景L2需要兼容模型缓存；仅安装可选Python依赖不会下载权重，缺缓存时保持不可用。用户媒体与第三方图片视频均不随包分发。研究来源信息与使用边界见 `../research/THIRD_PARTY_NOTICES.md`。
