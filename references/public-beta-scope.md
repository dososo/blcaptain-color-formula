# 公开测试范围与已知限制

状态：v4.9.1 公开测试范围。GitHub、Release 与冷安装状态以对应标签和 Release 页面为准；本文不表示全部素材已经获得人工审美通过。

## 本次产品承诺

正式目录共 32 个调色公式：31 个支持照片，31 个支持普通 SDR 视频。法式暖调仅照片，夜景黑金仅视频，其余 30 个同时支持两种媒体。所有声明支持的入口都可直接选择、建立计划并执行；研发历史状态不再限制或污染公开清单。

“全部可执行”不等于“任意素材都适配”。每个输入仍独立检查色彩空间、动态范围、黑白位、剪切、综合色彩、肤色与记忆色风险、变化量和视频时序。安全预演不合格时会拒绝当前素材、方向或强度，并保留原文件。只有用户明确确认当前 `plan_id` 才能渲染。

用户提供自己的 JPEG／PNG 照片或普通 SDR 视频，在本地完成诊断、方向选择、确认方案、生成新文件、查看前后对比与反馈。视频成片与短对比分别标识；短预览不能代替完整连续回放及声音检查。

## 执行、审美和展示证据分开

- 可执行：代码中存在真实配方与对应媒体链路，可被清单、选择和计划入口调用。
- 技术通过：只证明该次输出满足已执行的编码、色彩标签、范围与安全门。
- 人工接受：属于素材级结论，只绑定被看到的原片、配方、强度、计划和最终结果，不外推到同名公式的其他素材。
- 公开公式对比：使用权利清楚的公开素材展示视觉方向，不等于人工接受。

公开图谱逐项列出 31 张照片对比与 31 条视频对比，并优先复用许可允许公开、原片／成片／哈希可追溯且已被队长明确接受的最终结果。许可不清、用户私有、仅技术通过或过程件不进入图谱。素材按调整余量名称盲选，不按公式名称寻找已经自带目标色的原图。

## 不在本版保证范围

全局调色是核心。RAW、未识别 Log、HDR／PQ／HLG／Dolby Vision、跨 App 逐参数或逐像素等效、任意语义局部与视频语义跟踪不属于本版保证。低对比画面不能仅凭外观认定为 Log。

可选语义模型依赖兼容的本地模型缓存；仅安装 Python 依赖不会下载权重，缺缓存时自动降级。当前冷安装验证平台为 macOS；Windows 与 Linux 尚未完成同等级冷安装验收。

## 安装与许可边界

候选包需要 Python 及独立安装的 FFmpeg／ffprobe，不捆绑这些程序或模型。Python 3.9+ 是无第三方包的核心运行合同；完整开发仓库的研究、数值与可选能力测试使用带开发依赖的 Python 3.10.18，两者不能混称同一测试范围。
