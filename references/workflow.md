# 交互与确认工作流

## 三道主门与构图独立门

1. **视觉方向门**：默认推荐 3 个方向，也允许查看全部风格或同时比较 2～3 个；这不是渲染授权。
2. **构图／几何局部确认门**：裁切、旋转或单个径向注意力中心必须用结构化计划展示理由、范围与代价；无明确确认时保持原构图与默认中心。
3. **调色执行门**：展示完整确认单和L0～L3能力声明，用户明确确认当前 `plan_id` 后才能渲染。
4. **审美接受门**：展示结果后，用户决定接受或继续微调；“接受”不是覆盖原片的授权。

状态按 `收到素材 → 探测 → 形成视觉简报 → 补问 → 给3个推荐/全部风格 → 可选构图计划 → 生成调色计划 → 等待确认 → 渲染 → 技术验收 → 展示 → 接受/修改` 单向推进。`plan_id`绑定源文件、视觉简报、构图、适应性一级校正、正式配方、感知强度、曲线、HSL、色彩处理管线和输出路径；任何内容、源文件指纹或输出路径变化时，必须拒绝旧令牌并退回等待确认。

## 默认问题

最多询问四项，已有信息则跳过：

1. 想表达什么：安静、辽阔、亲密、孤独、锋利、温暖，或只做自然修复。
2. 强度：轻微 30%、明显 55%、强烈 80%。推荐从 55% 开始。
3. 人工验收重点是什么：肤色、天空、商品真实颜色、暗部细节。默认只记录并提醒检查；只有在 plan 显式加 `--detect-local`、对应后端与类别真实可用，并在 render 用 `--confirm-local` 单独确认策略时，L2 语义局部才会实际执行。多人肤色按人物实例一对一派生，无法唯一匹配的实例单独降级。
4. 用于哪里：小红书照片、短视频、存档或专业软件继续制作。

确认单必须包含：源文件、媒体类型与色彩解释、输入/工作/输出色域、视觉命题、构图动作、适应性一级校正、风格、输入强度与实际感知强度、人工验收重点、限制、输出路径、原片不覆盖声明、`plan_id`。Display P3 照片应直接说明“保持 P3，不需要先转 sRGB”；无标签照片应说明“确认后按 sRGB 解释”。

## 视觉导演原则

- 先定“为什么这样看”，再定“滑杆调多少”。视觉简报统一主体、空间层次、线条走向、形状关系、光线逻辑和情绪余韵。
- 一级校正只解决可读性：依据输入中位亮度、黑白端分布和配方相对EV计算稳定的全局校正，不把所有素材拉向固定亮度，不宣称恢复已经剪切的高光，也不逐帧漂移。
- 创意塑形负责取舍：每套配方必须有一个主手势，其他参数为它服务，避免平均用力造成“什么都有、什么都不突出”。
- 强度只经过一次感知映射，不再通过最终混合二次平方衰减；55%、80%、100% 应形成递增且可解释的视觉差异。
- 方向审计检查影调跨度、综合色彩、局部对比和中心／边缘启发式分离。只有代理确实观察当前素材并声明语义简报时，三项可测方向同时相反才阻断；否则只记录，避免用合成夹具伪装审美判断。
- 自动变化指标只检查“确实发生变化且没有明显技术破坏”，不声称判断作品是否高级、动人或获奖。

## 修改规则

用户说“再暖一点”等反馈时，先总结变化并生成一个新计划。每次只改变一个主要维度，便于比较；从原文件重渲染，禁止在上一版结果上叠加。

用户一次选择多个风格时，为每个风格生成独立计划、独立输出与独立 `plan_id`。多张素材先询问“统一风格”还是“逐张设计”；即使统一风格，也允许每张素材单独设置强度。

结构化微调文件只允许 `shadow_lift`、`highlight_shift` 与 `hsl_bands`。每次微调使用新的 `variant`、输出路径和 `plan_id`，仍须重新确认。HSL 是宽色带处理，不得描述成肤色或天空语义蒙版。

## 展示规范

- 照片：分别展示原图、结果图和等尺寸左右对比图；执行裁切时，对比图中的原图使用同一裁切范围，避免尺寸误导。
- 视频：分别展示原视频、结果视频和最长 8 秒的并排对比视频；结果保留音频，对比预览默认静音。启用 `--shot-grade` 后执行镜头检测、逐镜头一级校正、锚点匹配和共享 Look，镜头内参数恒定且不跨硬切平滑；局部语义选区的跨帧跟踪仍属 L3 未实现，完整连续回放仍必须人工验收。
- 同时给出 JSON 回执，包含哈希、命令参数、输出路径和音频保留状态。

## 失败恢复

- 输入无法读取：停止，列出具体路径或格式问题。
- 色彩空间不可信：按 `color-management.md` 的支持矩阵处理；仅无标签照片和 SDR 视频允许在确认单中显式假设，其他未知或未支持色域停止，不得猜测。
- 确认不匹配：拒绝渲染，重新展示当前确认单。
- 渲染或验收失败：保留原文件，报告日志，不把半成品称为结果。

技术验收证明文件可读、尺寸合理、目标色彩标签与位深正确、音频是否保留、原片未变、感知变化是否达到配方下限且未越过安全上限；肤色是否自然、氛围是否符合预期、作品是否具有情绪和记忆点必须由用户完成审美接受。
