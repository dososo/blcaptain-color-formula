# 安全策略 / Security Policy

## 支持版本

安全修复面向最新公开 Release。研究分支和历史候选不作长期支持承诺。

Security fixes target the latest public release. Research branches and historical candidates are not long-term supported versions.

## 报告安全问题

请不要先公开包含用户媒体、私人路径、令牌或可复现利用细节的 Issue。请发送邮件至 [blteam2026@outlook.com](mailto:blteam2026@outlook.com)，标题以 `[BLCaptain Security]` 开头，并包含受影响版本、最小复现和影响范围。收到后会先确认问题，再决定修复与披露节奏。

Do not first publish an Issue containing user media, private paths, tokens, or exploit details. Email [blteam2026@outlook.com](mailto:blteam2026@outlook.com) with `[BLCaptain Security]`, affected version, minimal reproduction, and impact.

一般功能问题请使用 [GitHub Issues](https://github.com/dososo/blcaptain-color-formula/issues)。
