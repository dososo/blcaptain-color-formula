# BLCaptain v4.8 研究层数据说明

## 定位

本目录是候选数据暂存区，不是主 Skill 的执行配方库。数据只用于风格检索、研究比较、人工录入和后续标定。

任何 `research_candidate` 或 `heuristic_seed` 都不得直接触发渲染，不得声称与照片或视频软件一比一等价。进入执行层前，仍需完成参数映射、限幅、固定版本基准素材标定、真实照片与视频渲染、质量门禁和人工验收。

## 文件

- `research_candidates.json`：52个原创研究候选。统一覆盖照片与视频指导，保留意图向量、HSL和颜色分级结构；全部标记为未验证、不可执行。
- `recommendation_rules.json`：52 条仅用于候选排序的关键词规则。命中规则不等于用户确认。
- `sources.json`：36条事实型来源元数据；其中3条v1.3视频工具官方资料已在2026-08-20重新核验。
- `platform_seeds.json`：156 条平台手工起始种子。每条只保存标准起点，并用统一策略派生三档，共可得到 468 个参数档位组合；它们不是 468 套独立公式。
- `guidance_seeds.json`：156条照片手工指导种子，三档共468组。
- `video_guidance_seeds.json`：剪映、Premiere、DaVinci各52个视频手工起点，共156条、三档468组；包含时序策略、风险和不支持能力。
- `evaluation_scenarios.json`：24个照片场景与12个视频场景，不是渲染通过证明。
- `xiaohongshu-v3-candidates.json`：2026-08-24 登录态只读采集的225条唯一公开搜索卡片候选。只含规范化原帖 URL、笔记 ID、标题、可见日期／互动量和查询记录；不含作者身份、UID、令牌、第三方媒体或完整原文。平台出现滑块验证后已立即停止，且搜索切换发生结果滞后，因此这些记录只算候选线索，不算详情精读或精准关键词归因。
- `manifest.json`：数量与 SHA-256 清单。
- `build_guidance_seeds.py`：从已脱敏的平台标准起点确定性派生三档手工指导参数。
- `build_video_guidance_seeds.py`：从52个统一意图确定性生成视频指导种子和视频评测场景。
- `validate_research_data.py`：数量、引用、类型、状态、字段集合和禁止内容自检。

## 关键修正

1. 将“高／最高频／热门”等未重新验证的表述改为 `popularity_claim: not_made`。
2. 所有候选统一使用 `confidence: unverified` 和 `visual_validation: not_performed`。
3. 将可能让人误认成品牌模拟的候选名改为描述性色彩名称；来源元数据中的品牌名仅用于准确标识官方资料。
4. 不分发 60 条第三方完整参数、原帖文字、截图、图片、视频、滤镜或 LUT。
5. 原始 R 编号不进入候选或平台种子；证据仅保留来源 ID，并把非官方内容限定为风格灵感。
6. 平台种子固定为 `manual_only`、`uncalibrated`、`executable: false`、`mapping_verified: false`。
7. 小红书 v3 候选固定为 `research_candidate_layer_only` 和 `search_card_verified`；不得据此宣称“全站热门”，也不得把查询词当作每条笔记内容标签。

## 数值语义

- `intent_vector.exposure_ev` 是相对曝光意图，允许范围为 -2 至 +2。
- 其余基础意图值范围为 -100 至 +100，但不是任何应用的原生量纲。
- HSL 色相、颜色分级色相与普通滑杆使用不同量纲，必须按独立字段解释。
- 保守、标准、大胆档通常来自 0.65、1.0、1.25 的设计强度；平台边界可以限幅，因此不是严格线性恒等式。

## 晋级执行层的最低门禁

1. 锁定应用或渲染后端版本。
2. 明确每个字段的单位、方向、限幅和不支持项。
3. 使用覆盖肤色、动态范围、白平衡、压缩和夜景噪点的固定基准集。
4. 记录同图导出、直方图、剪切、色差、噪声、边缘光晕和色带指标。
5. 通过真实照片与视频的前向测试和人工验收。
6. 生成新的执行配方 ID；不得用名称相似覆盖现有配方。

## 自检

在本目录执行：

```bash
python3 validate_research_data.py
```
